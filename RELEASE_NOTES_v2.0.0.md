# G316 X 98 SignalRGB Plugin v2.0.0

First public stable release candidate.

## Working on tested hardware

- Per-key RGB
- 30-zone RGB light bar
- SignalRGB canvas effects
- Full numpad
- Turkish/ISO special-key mapping
- Left Ctrl / Left Shift / Left Alt

## Tested device

```text
VID: 046D
PID: C36B
Layout: Turkish / ISO
```

## Installation

Download `Logitech_G316_X_98.js`, place it in SignalRGB's custom plugins folder using the Plugins button on the device information page, and restart SignalRGB.
